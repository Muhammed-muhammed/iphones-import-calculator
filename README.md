# iPhone Import Calculator 📱💸

This project helps analyze the profitability of importing iPhones into Iran by comparing global market prices to registry and customs costs.

## 🧠 What It Does
- Fetches real-time iPhone prices from global APIs
- Applies Iranian registry rules to estimate domestic cost
- Calculates and visualizes the price gap
- Suggests which models are most cost-effective for import
- Exports comparison data to Excel for further analysis

## 🔧 Tech Stack
- React
- TypeScript
- Axios
- Chart.js (or Recharts)
- XLSX (for Excel export)
- Custom CSS for layout and UI polish
